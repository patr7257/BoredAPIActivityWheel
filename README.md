# BoredAPIActivityWheel

A spin-a-wheel web app that fights boredom: spin the wheel and get a random activity from
the Bored API, with filters for price, number of participants, and activity type.

**Status: idea stage.** Nothing is designed or built yet. The concept, API facts, and open
questions live in [IDEA.md](IDEA.md); the design session will fill in [PLAN.md](PLAN.md).

This project gets its own repo and will later be showcased on the portfolio website
(`patr7257/PatrickRobelWeb`).
